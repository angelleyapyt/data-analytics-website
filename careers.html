CAREER 01

Data Analyst

The work for data analyst is collects, cleans, analyses and interprets data sets to produce useful information for organisations to make a better decision.

Typical Responsibilities

  • Collect and clean data
  • Analyse datasets
  • Create reports
  • Build dashboards
  • Communicate insights
Excel SQL Power BI Python
📈

CAREER 02

Business Intelligence Analyst

A Business Intelligence Analyst examines business information and creates reports or dashboards that support organisational decision-making.

Typical Responsibilities

  • Analyse business performance
  • Create dashboards
  • Monitor KPIs
  • Identify business trends
  • Support management decisions
Power BI Tableau SQL Excel
🤖

CAREER 03

Data Scientist

A Data Scientist works with large and complex datasets and may use statistics, programming and machine learning to develop analytical models.

Typical Responsibilities

  • Analyse large datasets
  • Develop statistical models
  • Build predictive models
  • Apply machine learning
  • Communicate complex findings
Python R SQL Machine Learning
